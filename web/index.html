App Android

O APK empacota este site num WebView. Ele funciona em dois modos:

  • Conectado: aponta para o servidor no seu PC/RDP (http://SEU_IP:8000) e usa a geração completa em Python.
  • Offline: geradores em JavaScript rodam no próprio aparelho (projetos, modelos simples, texturas até 2k) — sem servidor.

O build do APK é feito pelo GitHub Actions (.github/workflows/build-apk.yml): abra a aba Actions → Arkher APK no repositório e rode o workflow; o artefato arkher-ai.apk fica disponível para baixar e instalar.

Servidor de geração

No navegador, deixe vazio para usar o mesmo host do site. No APK, informe o endereço do seu PC/RDP na rede (ex.: http://192.168.0.20:8000).
